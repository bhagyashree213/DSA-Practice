## 📖 Practicals Overview

### Linear Search

Searches for an element by checking each element of the array one by one.

### Binary Search

Searches for an element in a **sorted array** by repeatedly dividing the search range into half.

### Bubble Sort

Sorts an array by repeatedly comparing adjacent elements and swapping them when they are in the wrong order.

### Swap of Two Numbers

Swaps the values of two numbers using a temporary variable.

### Selection Sort

Sorts an array by repeatedly finding the smallest element from the unsorted part and placing it at the correct position.
