# DS Practicals

This repository contains **Data Structures practical programs implemented in C**.

## 📚 Practicals

| No. | Program       | File                 |
| --- | ------------- | -------------------- |
| 1   | Linear Search | `01_Linear_Search.c` |
| 2   | Binary Search | `02_Binary_Search.c` |

## 🛠️ Language

* **C**

## ▶️ How to Run

Compile the program using GCC:

```bash
gcc 01_Linear_Search.c -o linear_search
./linear_search
```

For Binary Search:

```bash
gcc 02_Binary_Search.c -o binary_search
./binary_search
```

This repository is created to practice and maintain **Data Structures and Algorithms practical programs in C**.

More practical programs will be added as the course progresses.
