## ▶️ How to Run

### Prerequisites

Make sure **GCC** is installed on your system.

Check GCC installation:

```bash
gcc --version
```

### Compile the Program

For example:

```bash
gcc 08_FindDuplicateElements.c -o FindDuplicateElements
```

### Run the Program

**Windows:**

```bash
FindDuplicateElements
```

**Linux / macOS:**

```bash
./FindDuplicateElements
```
